## 1. commit 概念
1. commit 是 Git 的版本提交，记录一次完整的代码快照。
2. 每次 commit 都会生成唯一哈希值，保存修改内容、作者、时间、说明。
3. 一次 commit 只做一件事，方便回溯、排查问题、团队协作。
4. 常用场景：功能完成、bug 修复、文件修改。

## 2. branch 概念
1. branch 是独立开发线，不影响主代码。
2. 作用：并行开发、隔离风险、版本管理。
3. 主分支通常叫 master/main，功能分支从主分支分出。
4. 常用场景：开发新功能、修复bug、测试代码。

## 3. HEAD 概念
1. HEAD 指向当前所在分支的最新提交。
2. 切换分支时，HEAD 自动跟着切换。
3. 理解 HEAD 能清楚当前仓库状态。
4. 常和分支、回退版本一起使用。

## 4. 暂存区 staging area
1. 暂存区是工作区与仓库之间的临时区域。
2. git add 把文件放入暂存区，git commit 提交到仓库。
3. 可以选择部分文件提交，让提交更干净。
4. 作用：控制提交内容，避免误提交无关文件。

## 5. remote 远程仓库
1. remote 是托管在网络上的 Git 仓库（如 GitHub/Gitee）。
2. 本地仓库在自己电脑，远程仓库在服务器。
3. 团队协作必须用远程仓库同步代码。
4. 常用命令：git push、git pull、git remote。
